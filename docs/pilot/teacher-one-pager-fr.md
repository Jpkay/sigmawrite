# Pilote Sigmawrite — fiche enseignant

## En 10 minutes

1. Créez votre classe, puis affichez le code d’inscription.
2. Le code de classe autorise immédiatement les élèves invités, quel que soit leur âge.
3. Le diagnostic adaptatif localise les prérequis maîtrisés, fragiles et manquants.
4. Assignez une lecture ou une micro-session de compétence.
5. Consultez les preuves et exportez le rapport CSV.

Sigmawrite ne remplace pas votre jugement. L’IA propose du contenu et du
feedback; les règles linguistiques, le graphe, les scores et les décisions de
publication restent contrôlés et traçables.

À surveiller chaque semaine : élèves sans activité, étapes bloquées, réussite
hors de la zone 80–85 %, et qualité des items signalés.
