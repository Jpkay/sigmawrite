# Pilote Sigmawrite — fiche parent

Votre enfant lit des textes choisis selon ses intérêts et travaille les bases
qui bloquent réellement la suite. Le rapport hebdomadaire montre les minutes,
la réussite, les points forts, les besoins et des exemples de textes lus avec
aisance ou avec soutien.

Il n’y a ni publicité, ni profil public, ni comparaison sociale, ni chat IA
libre. Vous pouvez retirer le consentement, exporter les données ou demander
leur suppression depuis l’espace Confidentialité.
