# Leçons de rédaction : propositions à relire

18 leçons, 36 exemples commentés et 36 décisions guidées. Brouillons non publiés. Les exercices guidés aident à apprendre ; ils ne prouvent pas une rédaction autonome.

## Décrire ce qui se passe ou se répète

Comment garder mes verbes cohérents quand je décris une scène ?

Chaque mercredi, Nora ouvre le local. Ses voisins apportent leurs outils et nous réparons des objets.

Le texte présente une habitude. Les verbes sont au présent, mais leur terminaison dépend de leur sujet : Nora ouvre, ses voisins apportent, nous réparons.

Un chien traverse la place. Deux passants le regardent, puis une enfant appelle sa mère.

Pour chaque nouvelle phrase, retrouve qui agit avant de choisir la forme du verbe. Le présent peut aussi décrire une scène en cours.

À retenir : Choisis un repère de temps, puis vérifie le sujet de chaque verbe.

Limite : Un paragraphe peut changer de temps si son sens le demande. Cette leçon travaille une description au présent, pas tous les emplois de ce temps.

### Exercices guidés

Continue cette description au présent : « Les musiciens s’installent. Ensuite, nous… »

- préparons les micros.
- préparent les micros.

Indice : Cherche le sujet du verbe à compléter.

Réponse : préparons les micros.

Explication : Avec nous, préparer donne préparons au présent.

Continue l’habitude décrite : « Tous les soirs, Mila lit. Son frère… »

- dessine près d’elle.
- dessinent près d’elle.

Indice : Son frère désigne une seule personne.

Réponse : dessine près d’elle.

Explication : Le sujet singulier son frère demande dessine.

## Décrire le décor et les habitudes du passé

Comment montrer ce qui se passait autrefois ?

Autrefois, le café ouvrait tôt. Nous y prenions une boisson et les habitués discutaient près du comptoir.

Ces actions se répétaient. L’imparfait présente ici des habitudes : ouvrait, prenions, discutaient.

La salle était sombre. Une lampe éclairait le bureau et des papiers couvraient le sol.

L’imparfait décrit aussi une situation passée. Vérifie les sujets : une lampe éclairait, des papiers couvraient.

À retenir : Pour décrire une situation ou une habitude passée, utilise l’imparfait et accorde chaque verbe avec son sujet.

Limite : L’imparfait ne signifie pas forcément une action longue. Le point de vue du récit compte aussi.

### Exercices guidés

Complète cette habitude passée : « Chaque matin, nous… »

- rangions les paniers.
- rangeaient les paniers.

Indice : Le sujet est nous.

Réponse : rangions les paniers.

Explication : À l’imparfait, nous rangions porte la terminaison -ions.

Choisis la suite qui décrit le décor passé : « Les murs étaient blancs. Une horloge… »

- sonnait dans le couloir.
- sonnaient dans le couloir.

Indice : Une horloge est un sujet singulier.

Réponse : sonnait dans le couloir.

Explication : Une horloge sonnait garde le sujet singulier et l’imparfait.

## Annoncer une action prévue

Comment dire ce que nous prévoyons de faire ?

Le colis est prêt. Je vais le déposer et mes voisins vont prévenir le destinataire.

Le futur proche se construit avec aller au présent suivi d’un infinitif : vais déposer, vont prévenir. Seul aller change avec le sujet.

Nous allons vérifier l’adresse. Ensuite, tu vas fermer le carton.

Vérifier et fermer restent à l’infinitif. Nous allons et tu vas indiquent qui agit.

À retenir : Conjugue aller au présent, puis ajoute l’action à l’infinitif.

Limite : Le futur proche peut annoncer un projet assez éloigné. Il ne suffit pas de compter les minutes avant l’action.

### Exercices guidés

Complète le projet : « Vous… »

- allez installer les tables.
- allez installez les tables.

Indice : Après aller, le second verbe reste à l’infinitif.

Réponse : allez installer les tables.

Explication : Installer reste à l’infinitif après allez.

Complète : « Les bénévoles… »

- vont accueillir les visiteurs.
- va accueillir les visiteurs.

Indice : Les bénévoles correspond à ils ou elles.

Réponse : vont accueillir les visiteurs.

Explication : Au présent, aller donne vont avec un sujet pluriel.

## Raconter ce qui vient de se terminer

Comment raconter plusieurs actions tout juste achevées ?

Je viens de poster la lettre. Mes amis viennent de quitter le bureau de poste.

Le passé récent se construit avec venir au présent, de, puis un infinitif. Viens et viennent changent avec le sujet.

Nous venons de recevoir une réponse. Vous venez de découvrir la nouvelle.

Recevoir et découvrir restent à l’infinitif. Il faut garder les trois parties : venir, de, action.

À retenir : Pour une action tout juste terminée, utilise venir au présent + de + infinitif.

Limite : Venait de exprime une action récente par rapport à un moment passé. Cette leçon travaille vient de au présent.

### Exercices guidés

Complète : « Tu… »

- viens de terminer ton affiche.
- vient de terminer ton affiche.

Indice : Conjugue venir avec tu.

Réponse : viens de terminer ton affiche.

Explication : Tu viens prend un s, puis de terminer reste inchangé.

Complète : « Les artistes viennent… »

- de signer leurs œuvres.
- signent leurs œuvres.

Indice : Repère la partie manquante de venir de + infinitif.

Réponse : de signer leurs œuvres.

Explication : Après viennent, on écrit de signer.

## Raconter des actions accomplies

Comment enchaîner les événements d’un souvenir ?

Hier, Karim a fermé la boutique. Ses collègues sont partis et nous avons éteint les lumières.

Le passé composé raconte ici des actions accomplies. Chaque verbe comprend un auxiliaire, avoir ou être au présent, et un participe passé.

Ana et Lou sont rentrées. Elles ont posé leurs sacs, puis Ana a téléphoné.

Avec être, le participe s’accorde ici avec le sujet : Ana et Lou sont rentrées. Avec avoir, il ne s’accorde pas simplement parce que le sujet est pluriel : elles ont posé.

À retenir : Pour chaque action accomplie, vérifie l’auxiliaire, le participe passé et les accords nécessaires.

Limite : Avec avoir, un complément direct placé avant peut entraîner un accord. Les verbes pronominaux demandent aussi une analyse particulière.

### Exercices guidés

Complète : « Léa et Inès… »

- sont arrivées à midi.
- sont arrivé à midi.

Indice : Arriver se construit ici avec être. Qui est arrivé ?

Réponse : sont arrivées à midi.

Explication : Avec être, arrivées s’accorde avec les deux personnes féminines.

Complète : « Nous… »

- avons choisi une date.
- avons choisir une date.

Indice : Après l’auxiliaire, il faut un participe passé.

Réponse : avons choisi une date.

Explication : Le participe passé de choisir est choisi, pas choisir.

## Présenter ce qui se passera plus tard

Comment écrire un projet au futur simple ?

L’an prochain, je participerai au concours. Mes amis prépareront le décor et nous choisirons la musique.

Le futur simple place ces actions dans l’avenir. Les terminaisons varient avec le sujet : -ai, -as, -a, -ons, -ez, -ont.

Tu viendras avec nous. Nous serons prêts et vous aurez une place au premier rang.

Certains verbes changent de base : venir donne viendr-, être ser-, avoir aur-. On ajoute ensuite la terminaison du sujet.

À retenir : Associe la base du futur à la terminaison du sujet, puis garde un repère temporel clair.

Limite : Le futur ne se forme pas toujours en ajoutant une terminaison à l’infinitif entier : prends le temps de vérifier les bases particulières.

### Exercices guidés

Complète le projet : « Nous… »

- visiterons le musée.
- visiteront le musée.

Indice : Avec nous, la terminaison est -ons.

Réponse : visiterons le musée.

Explication : Nous visiterons termine par -ons.

Complète : « Demain, elle… »

- viendra nous aider.
- venirra nous aider.

Indice : Le futur de venir utilise la base viendr-.

Réponse : viendra nous aider.

Explication : Viendr- + -a donne viendra.

## Raconter ce qui était déjà fait

Comment expliquer un événement antérieur dans un récit passé ?

À dix heures, le livreur est arrivé. Nous avions préparé les cartons et Zoé avait libéré l’entrée.

Le récit est déjà au passé. Avions préparé et avait libéré racontent ce qui était accompli avant l’arrivée : c’est le plus-que-parfait.

Quand la pluie a commencé, les promeneuses étaient rentrées. Elles avaient fermé les fenêtres.

Le plus-que-parfait utilise être ou avoir à l’imparfait, puis le participe passé. Rentrées s’accorde ici avec les promeneuses.

À retenir : Installe un moment passé, puis utilise le plus-que-parfait pour ce qui était accompli auparavant.

Limite : Tous les verbes d’un récit passé ne doivent pas être au plus-que-parfait. Il sert à montrer une antériorité par rapport à un autre repère passé.

### Exercices guidés

Les préparatifs précèdent l’ouverture passée. Complète : « Les employés… »

- avaient nettoyé la salle avant l’ouverture.
- ont nettoyer la salle avant l’ouverture.

Indice : Choisis un auxiliaire à l’imparfait et un participe passé.

Réponse : avaient nettoyé la salle avant l’ouverture.

Explication : Avaient nettoyé exprime l’action accomplie avant l’ouverture.

Complète l’action antérieure : « Quand le bus est passé, elles… »

- étaient déjà parties.
- étaient déjà parti.

Indice : Avec être, le participe s’accorde ici avec elles.

Réponse : étaient déjà parties.

Explication : Parties s’accorde au féminin pluriel.

## Imaginer ce qui serait possible

Comment raconter une possibilité qui dépend d’une condition ?

Si nous avions un atelier, nous fabriquerions nos décors. Ma sœur peindrait les panneaux et je réparerais les accessoires.

La condition imaginaire utilise ici si + imparfait. Les conséquences utilisent le conditionnel présent : fabriquerions, peindrait, réparerais.

Avec davantage de place, ils pourraient recevoir du public. Nous serions heureux de les aider.

Le conditionnel présent associe généralement la base du futur aux terminaisons de l’imparfait. Certaines bases sont particulières : pourr-, ser-.

À retenir : Pour cette hypothèse, écris la condition à l’imparfait et la conséquence au conditionnel présent.

Limite : Le conditionnel sert aussi à exprimer une demande polie ou une information incertaine. Ne mets pas automatiquement un conditionnel après si.

### Exercices guidés

Choisis la conséquence : « Si j’avais plus de temps, je… »

- lirais ce roman.
- lis ce roman.

Indice : La phrase imagine une possibilité dépendant d’une condition.

Réponse : lirais ce roman.

Explication : Lirais est au conditionnel présent et convient à cette hypothèse.

Complète : « Si elles habitaient plus près, elles… »

- viendraient chaque semaine.
- viendrait chaque semaine.

Indice : Le sujet est elles.

Réponse : viendraient chaque semaine.

Explication : Viendraient prend -aient avec elles.

## Exprimer un souhait ou une nécessité

Comment écrire ce que je souhaite que les autres fassent ?

Je souhaite que chacun trouve sa place. Il faut que nous soyons attentifs et que les nouveaux puissent participer.

Après ces expressions de souhait ou de nécessité, les verbes sont au subjonctif présent : trouve, soyons, puissent.

La responsable veut que tu viennes tôt. Elle demande aussi que vous ayez votre matériel.

Le sujet peut changer dans chaque proposition. Vérifie tu viennes et vous ayez, plutôt que de recopier une seule terminaison.

À retenir : Repère l’expression qui appelle le subjonctif, puis conjugue selon le sujet de la proposition.

Limite : La présence de que ne suffit pas : « Je sais qu’il vient » utilise l’indicatif. Le sens et la construction commandent le choix.

### Exercices guidés

Complète : « Il faut que nous… »

- fassions une pause.
- faisons une pause.

Indice : Après il faut que, utilise le subjonctif.

Réponse : fassions une pause.

Explication : Avec nous, faire donne fassions au subjonctif présent.

Complète : « Je souhaite qu’ils… »

- soient disponibles.
- sont disponibles.

Indice : Je souhaite que introduit ici un souhait.

Réponse : soient disponibles.

Explication : Être donne soient avec ils au subjonctif présent.

## Donner des consignes reliées

Comment guider quelqu’un sans répéter son nom à chaque phrase ?

Observe la carte, puis choisis une direction. N’oublie pas ta lampe.

Ces phrases s’adressent directement à une personne. L’impératif n’a pas de sujet exprimé. L’interdiction encadre le verbe avec ne et pas.

Avancez jusqu’au repère, puis attendez le signal. Restons ensemble pour la suite.

Avancez et attendez s’adressent à plusieurs personnes ou à une personne vouvoyée. Restons inclut la personne qui parle dans l’action proposée.

À retenir : Choisis tu, nous ou vous comme destinataire implicite, puis relie tes consignes sans exprimer ce sujet.

Limite : Les formes ne se déduisent pas toutes du présent : sois, aie, va. Le s réapparaît notamment dans vas-y et manges-en.

### Exercices guidés

Adresse cette consigne à un ami :

- Ferme la fenêtre, puis écoute.
- Tu fermes la fenêtre, puis tu écoutes.

Indice : Une consigne à l’impératif n’exprime pas le sujet tu.

Réponse : Ferme la fenêtre, puis écoute.

Explication : Ferme et écoute donnent directement les consignes à l’impératif.

Adresse une interdiction à plusieurs personnes :

- Ne courez pas dans le couloir.
- Vous ne courez pas dans le couloir.

Indice : Choisis l’impératif sans sujet exprimé.

Réponse : Ne courez pas dans le couloir.

Explication : Ne courez pas forme une interdiction à l’impératif.

## Faire avancer une histoire écrite

Comment raconter les actions successives d’un personnage ?

La voyageuse souleva le rideau. Elle aperçut une silhouette, puis recula de quelques pas.

Dans ce récit écrit, le passé simple fait avancer les événements. Les formes souleva, aperçut et recula dépendent du verbe, pas seulement du sujet.

Les gardes ouvrirent le portail. Nous franchîmes le seuil et je reconnus enfin la maison.

Les terminaisons changent avec le sujet et la famille du verbe. Compare ouvrirent, franchîmes et reconnus.

À retenir : Pour faire avancer ce récit, choisis le passé simple et vérifie la forme de chaque verbe avec son sujet.

Limite : Le passé simple n’exprime pas nécessairement une action courte. Il est surtout employé dans les récits écrits et coexiste souvent avec l’imparfait.

### Exercices guidés

Continue le récit au passé simple : « Le capitaine entra. Les marins… »

- saluèrent leur capitaine.
- saluaient leur capitaine.

Indice : On demande ici une nouvelle action au passé simple.

Réponse : saluèrent leur capitaine.

Explication : Saluèrent est le passé simple de saluer avec les marins.

Continue au passé simple : « Nous… »

- prîmes le sentier de gauche.
- prenions le sentier de gauche.

Indice : Le passé simple de prendre utilise ici prîmes.

Réponse : prîmes le sentier de gauche.

Explication : Nous prîmes raconte ici une action successive au passé simple.

## Relier le décor et les événements

Comment passer de ce qui se passait à ce qui est arrivé ?

Le four chauffait et nous préparions la pâte. Soudain, la minuterie a sonné.

L’imparfait présente les actions en cours. Le passé composé présente ici l’événement qui survient dans cette situation.

La salle était vide. Nous avons installé les chaises pendant une heure, puis les invités sont arrivés.

Une action au passé composé peut durer : avons installé couvre une heure délimitée. Le choix ne dépend donc pas seulement d’une action courte ou longue.

À retenir : Distingue le cadre ou l’action en cours des événements présentés comme accomplis.

Limite : Un même événement peut être présenté différemment selon le point de vue. Évite la règle trompeuse « court = passé composé, long = imparfait ».

### Exercices guidés

Choisis le récit qui distingue le cadre en cours de l’événement :

- Le téléphone sonnait depuis un moment quand j’ai décroché.
- Le téléphone a sonné depuis un moment quand je décrochais.

Indice : Le cadre est déjà en cours lorsque l’événement arrive.

Réponse : Le téléphone sonnait depuis un moment quand j’ai décroché.

Explication : Sonnait installe la situation en cours ; ai décroché présente l’événement.

Choisis la suite pour une période terminée : « Hier, la route était fermée. Nous… »

- avons attendu deux heures, puis nous sommes repartis.
- attendions deux heures, puis nous sommes repartis.

Indice : La période d’attente est présentée comme terminée avant le départ.

Réponse : avons attendu deux heures, puis nous sommes repartis.

Explication : Avons attendu convient à cette période délimitée, même si elle dure deux heures.

## Faire comprendre l’ordre des actions

Comment éviter que le lecteur se perde dans mon récit ?

D’abord, Yara a mesuré le tissu. Ensuite, elle l’a découpé. Enfin, elle a cousu les morceaux.

Les mots d’abord, ensuite et enfin indiquent la succession. L’ordre des phrases correspond ici à celui des actions.

Pendant que Yara cousait, son frère préparait les attaches. Plus tôt, il avait dessiné le modèle.

Pendant que montre des actions simultanées. Plus tôt et avait dessiné signalent un retour à une action antérieure.

À retenir : Décide ce qui se passe avant, après ou en même temps, puis choisis les liens et les temps qui le montrent.

Limite : Ajouter ensuite entre toutes les phrases ne suffit pas. Un récit peut revenir en arrière si ce retour est clairement signalé.

### Exercices guidés

Le sac est préparé avant le départ. Choisis l’ordre cohérent :

- D’abord, j’ai préparé mon sac. Ensuite, j’ai quitté la maison.
- D’abord, j’ai quitté la maison. Ensuite, j’ai préparé mon sac.

Indice : Respecte l’ordre donné dans la consigne.

Réponse : D’abord, j’ai préparé mon sac. Ensuite, j’ai quitté la maison.

Explication : La préparation précède le départ.

Les deux actions se passent en même temps. Choisis le lien adapté :

- Pendant que Sami peignait, Lou découpait les étiquettes.
- Après que Sami a peint, Lou a découpé les étiquettes.

Indice : Cherche un lien qui indique la simultanéité.

Réponse : Pendant que Sami peignait, Lou découpait les étiquettes.

Explication : Pendant que situe les deux actions au même moment ; après que les présente comme successives.

## Éviter les répétitions sans perdre le sens

Comment remplacer un nom tout en restant clair ?

J’ai trouvé une écharpe. Je la rapporte à sa propriétaire et je lui explique où elle était.

La remplace l’écharpe, complément direct de rapporte. Lui remplace à sa propriétaire, complément indirect de explique. Le choix dépend de la construction du verbe.

Les voisins attendent leurs colis. Je les apporte, puis je leur indique où signer.

Les remplace les colis ; leur remplace aux voisins. Ces pronoms se placent ici avant le verbe conjugué.

À retenir : Retrouve le nom remplacé et la construction du verbe avant de choisir et placer le pronom.

Limite : Si plusieurs noms peuvent être repris, répète le nom pour rester clair. La place des pronoms change dans certaines constructions, notamment à l’impératif affirmatif.

### Exercices guidés

Remplace « à Hugo » : « J’écris à Hugo, puis… »

- je lui envoie une photo.
- je le envoie une photo.

Indice : On envoie quelque chose à quelqu’un.

Réponse : je lui envoie une photo.

Explication : Lui reprend à Hugo et se place avant envoie.

Remplace « les affiches » : « Les affiches sont prêtes. Nous… »

- les accrochons dans l’entrée.
- leur accrochons dans l’entrée.

Indice : Accrocher quoi ? Les affiches, sans préposition.

Réponse : les accrochons dans l’entrée.

Explication : Les reprend le complément direct pluriel les affiches.

## Garder l’écriture des mots dans ses phrases

Comment écrire mes idées sans oublier la forme des mots ?

La fillette ouvre une bouteille. Elle la pose près de la fenêtre.

Pendant la rédaction, on doit retrouver la graphie des mots, leur façon de s’écrire. Bouteille garde ses deux l ; fenêtre garde son accent circonflexe.

Une adresse apparaît sur l’enveloppe. Je la recopie dans mon carnet.

Adresse possède deux s. Le son seul ne permet pas toujours de retrouver toutes les lettres. Mémoriser un mot en contexte aide à le réutiliser.

À retenir : Quand tu écris, retrouve la forme du mot entier, y compris les lettres muettes, les accents et les consonnes doubles.

Limite : Un mot bien écrit ne prouve pas que tous les mots le sont. Les accords et les terminaisons verbales demandent une vérification différente.

### Exercices guidés

Choisis la phrase dont le mot courant est bien écrit :

- Il note une adresse sur le papier.
- Il note une adresse sur le papiet.

Indice : Concentre-toi sur la fin du mot qui désigne le support.

Réponse : Il note une adresse sur le papier.

Explication : Papier s’écrit avec un r final. Ce r fait partie de la graphie du mot.

Choisis la phrase dont la graphie lexicale est correcte :

- La fillette remplit sa bouteille.
- La fillette remplit sa bouteile.

Indice : Observe la consonne à la fin de bouteille.

Réponse : La fillette remplit sa bouteille.

Explication : Bouteille s’écrit avec deux l.

## Vérifier les liens qui commandent les accords

Comment choisir les marques qui dépendent des autres mots ?

Les petites valises restent ouvertes.

Le déterminant les annonce le pluriel. Petites et ouvertes s’accordent ici avec valises au féminin pluriel ; restent s’accorde avec le sujet les petites valises.

La valise de mes voisins reste ouverte.

Le sujet principal est la valise, au singulier. Le groupe de mes voisins ne transforme pas le sujet en pluriel : on écrit reste ouverte.

À retenir : Relie chaque verbe à son sujet et chaque adjectif au nom qu’il décrit. Ne choisis pas une terminaison seulement d’après le mot le plus proche.

Limite : Ces liens couvrent des accords fréquents. D’autres règles, comme certains accords du participe passé, demandent une analyse supplémentaire.

### Exercices guidés

Choisis l’accord sujet-verbe correct :

- Le panier des vendeuses contient des fruits.
- Le panier des vendeuses contiennent des fruits.

Indice : Quel nom désigne ce qui contient les fruits ?

Réponse : Le panier des vendeuses contient des fruits.

Explication : Le noyau du sujet est panier, au singulier : contient.

Choisis les accords corrects :

- Des portes étroites ferment le passage.
- Des portes étroite ferment le passage.

Indice : L’adjectif décrit plusieurs portes.

Réponse : Des portes étroites ferment le passage.

Explication : Étroit s’accorde ici avec portes, féminin pluriel : étroites.

## Relire pour corriger l’écriture des mots

Comment améliorer ma première version sans changer mes idées ?

Première version : « Le messager porte une letre. Il connaît cette adrese. »
Version relue : « Le messager porte une lettre. Il connaît cette adresse. »

Relis lentement pour repérer les mots dont la graphie te paraît incertaine. Ici, lettre et adresse demandent chacun une consonne double. Les idées restent les mêmes.

Première version : « Elle ferme la fenêtre. »
Version relue : « Elle ferme la fenêtre. »

Une relecture peut confirmer une graphie déjà correcte. Il ne faut pas modifier un mot uniquement pour montrer qu’on a fait une correction.

À retenir : Compare tes deux versions : corrige les graphies incertaines sans supprimer les difficultés ni abîmer les mots déjà corrects.

Limite : Si la première version ne contient aucune faute de cette catégorie, elle ne permet pas de vérifier ta capacité à corriger une faute. Cela ne signifie pas un échec.

### Exercices guidés

Corrige la graphie sans supprimer l’idée : « Il prépare une surprize. »

- Il prépare une surprise.
- Il prépare quelque chose.

Indice : Corriger un mot est différent d’éviter de l’écrire.

Réponse : Il prépare une surprise.

Explication : Surprise conserve l’idée et rétablit le s.

La phrase « Le message est dans une enveloppe. » est déjà correcte. Quelle révision convient ?

- Le message est dans une enveloppe.
- Le message est dans une envelope.

Indice : Ne retire pas une lettre sans raison.

Réponse : Le message est dans une enveloppe.

Explication : Enveloppe possède deux p. Une version correcte peut rester inchangée.

## Relire les accords et les verbes

Comment corriger les liens entre les mots dans mon texte ?

Première version : « Les lumières éclaire la pièce. Une grande tables occupe le centre. »
Version relue : « Les lumières éclairent la pièce. Une grande table occupe le centre. »

Relie éclaire à son sujet pluriel les lumières : éclairent. Puis repère une, qui annonce un seul objet : table doit rester au singulier.

Première version : « Le bruit des machines réveille le voisin. »
Version relue : « Le bruit des machines réveille le voisin. »

Le mot machines est pluriel, mais le sujet principal est le bruit. La forme réveille était déjà correcte ; inutile de la mettre au pluriel.

À retenir : Relis en suivant les relations entre les mots, puis compare les versions pour vérifier que tes modifications corrigent réellement les erreurs.

Limite : Changer le sujet pour éviter un accord ne démontre pas que tu sais le corriger. Une phrase correcte n’a pas besoin d’être modifiée.

### Exercices guidés

Corrige seulement l’accord erroné : « Les rideaux cache la fenêtre. »

- Les rideaux cachent la fenêtre.
- Le rideau cache la fenêtre.

Indice : Garde plusieurs rideaux et corrige le verbe.

Réponse : Les rideaux cachent la fenêtre.

Explication : Cachent s’accorde avec les rideaux sans modifier l’idée.

Relis : « Les garçons prennent leurs sacs. » Quelle version conserve les accords corrects ?

- Les garçons prennent leurs sacs.
- Les garçons prenne leurs sacs.

Indice : Prendre doit rester accordé au sujet pluriel.

Réponse : Les garçons prennent leurs sacs.

Explication : Prennent est déjà correct avec les garçons.
