# Accord nom-adjectif : propositions à relire

32 questions : 16 analyses et 16 réponses écrites. Deux leçons et 12 exercices guidés. Non publié ; aucune approbation pédagogique enregistrée. Les réponses écrites portent sur un adjectif fourni, pas sur une rédaction autonome.

Les quatre contre-exemples ne contiennent pas d’adjectif. Les phrases de vérification diffèrent des exemples enseignés. Cela ne prouve pas que chaque élève ne les a jamais vues : un historique complet reste nécessaire.

## Trouver le nom qui commande l’accord

Quel nom l’adjectif décrit-il réellement ?

La veste de mon frère est grise.

Grise décrit la veste, pas le frère. Le nom veste impose ici le féminin singulier, même si frère est plus proche de l’adjectif.

Les feuilles de cet arbre sont jaunes.

Jaunes décrit plusieurs feuilles. L’adjectif prend les marques demandées par feuilles, pas par arbre.

Une grande tour. La tour est grande.

L’adjectif peut accompagner directement le nom ou lui être relié par un verbe comme être. Dans les deux cas, grande décrit tour.

Les coureurs avancent rapidement.

Rapidement précise comment ils avancent : c’est un adverbe. La phrase ne contient pas d’adjectif à accorder avec coureurs.

Limite : Le mot le plus proche n’est pas toujours celui qui commande l’accord. Certaines formes se ressemblent au masculin et au féminin ou au singulier et au pluriel : il faut analyser la relation, pas seulement la terminaison.

La robe de ma sœur est verte.

Quel mot commande l’accord de « verte » ?

Réponse : Le nom « robe », au féminin singulier.

Autres propositions ou formes rejetées : Le nom « sœur », parce qu’il est dans la même phrase. ; L’adjectif ne dépend d’aucun nom dans cette phrase. ; Le verbe détermine à lui seul le genre de l’adjectif.

« verte » décrit « robe ». L’accord dépend de ce nom, même si un autre groupe les sépare.

### analysis-absence-1

Les cyclistes roulent vite.

Quelle analyse de l’accord nom-adjectif est juste ?

Réponse : Cette phrase ne contient pas d’adjectif à accorder avec un nom.

Autres propositions ou formes rejetées : Le verbe est un adjectif accordé avec le premier nom. ; Chaque mot placé après un nom est un adjectif. ; Tous les mots de cette phrase prennent le genre du premier nom.

Il n’y a pas ici de relation nom-adjectif à analyser. Un verbe ou un adverbe n’est pas un adjectif simplement parce qu’il suit un nom.
