# Recognizing simple negation

Adds 16 sentence-analysis questions and a separate recognition lesson with four guided exercises for construction_negation_simple::reading-analysis. This complements the independently assessed writing target without sharing mastery between modes.

Eight questions contain ne…pas or n’…pas, including auxiliaries and preceding pronouns. Eight are actual counterexamples: affirmative statements, nonnegative questions or affirmative instructions. A description such as Les volets sont fermés is distinguished from grammatical negation. Counterexample metadata is attached only when the question's own sentence lacks the target, not merely because an option is wrong.
