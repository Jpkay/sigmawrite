# Accord du participe passé avec avoir : revue des brouillons

36 questions originales. Le participe masculin singulier est fourni pour isoler la décision d’accord. Aucune approbation humaine n’est enregistrée. Vérifier le COD, sa place, le genre et le nombre, la réponse et les limites de chaque explication.

## preceding-1

Complète la phrase avec le participe passé de « dessiner ».
Forme au masculin singulier : dessiné.

La planche que Sami a ___ raconte une aventure.

Réponse attendue : **dessinée**.

Justification : Sami a dessiné quoi ? La planche. Ce COD féminin singulier est placé avant le participe : dessinée.
