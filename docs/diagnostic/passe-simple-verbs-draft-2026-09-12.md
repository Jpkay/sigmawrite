# Four exact-verb passé simple pathways: unpublished revision 34

Adds separate production lessons for être, avoir, aller and faire. Each has six guided examples and twelve distinct sentence checks, covering all six persons. Contexts are written narratives, including narrators using je/nous and narration addressing a character or reader. The explanations distinguish supplied-tense form production from choosing an appropriate tense in independent writing.

The lessons explicitly address fus/fut/fûmes/fûtes, eus/eut/eûmes/eûtes, allai/allais, and fis/fit/fîmes/fîtes. An authored-form check compares each expected paradigm with the deterministic conjugator. The answer tests reject meaningful accent errors and corresponding imperfect/subjunctive substitutions. These are draft refinements of approved targets, not newly approved curriculum.
