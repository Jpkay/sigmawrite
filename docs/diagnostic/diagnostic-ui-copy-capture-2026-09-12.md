# Main diagnostic display-copy capture

The granular diagnostic now uses shared fixed copy for its main headings, instructions, state labels, buttons, notices and fallback errors. The server route records that same object for the authenticated student before returning the granular client. The legacy path is retained and is not falsely recorded as a granular delivery.

The unavailable-release response also passes through the ordinary delivery journal rather than returning an unrecorded error string. Capture failures withhold the response; no novelty or mastery permission is granted.

This is not a complete diagnostic UI capture contract. Counters assembled from runtime values, result-group wording, reconciliation messages, guided teaching, audio controls, feature rows and writing feedback still require their own capture coverage. Recording fixed copy conservatively includes branches that may not be painted. No historical student coverage is inferred.

The approved graph's inspected spelling rules explicitly require novel words, and the adapter passes those requirements through. Those rules were not relaxed by this change.
