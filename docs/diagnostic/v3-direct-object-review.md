## manga

Répartition candidate : learning.

Lina lit un manga.

Quelle analyse du complément d’objet direct (COD) est correcte ?

- « un manga » est le COD : c’est ce que Lina lit.
- « Lina » est le COD : c’est la personne qui lit.
- « lit » est le COD : ce mot indique l’action.
- Il n’y a pas de COD : la phrase contient seulement un sujet et un verbe.

Réponse : « un manga » est le COD : c’est ce que Lina lit.

Justification pour la revue : Lire quelque chose : un manga complète directement lit; Lina est le sujet.
