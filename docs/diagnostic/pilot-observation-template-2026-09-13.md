# Student pilot: teacher observation and review

Use one copy per student sitting. This is a blank record, not evidence that a review or pilot has happened. Use a student reference rather than a name; keep credentials out of this document.

## Sitting

- Student reference:
- Observer and date:
- Production deployment / content release:
- Diagnostic session reference:
- Start / finish / active minutes / pauses:
- Device and any interruptions:
- Completed diagnostic, opened results, started a lesson, completed an independent check: record each separately.

The initial diagnostic should take 30–40 active minutes. Learning can begin with unresolved skills; an untested skill is not a weakness. Guided lesson answers do not establish independent mastery.

## Skill-by-skill comparison

Record the teacher's expectation before reading the system result where practical. Name the exact skill: verb and tense, spelling rule, grammar construction, or reading task. Do not reduce the student to one overall level.

Distinguish an incorrect answer from a misunderstanding of the question, a typo, unfamiliar vocabulary, a guess, or a navigation problem. If the available evidence cannot distinguish them, record that uncertainty.
