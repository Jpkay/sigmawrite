# Guided repair completion and retry identity

The legacy remedial lesson used to accept browser-supplied correctness flags and update broad skill estimates once per answer. A lost successful response could cause the same answers to update estimates again. Guided exercises now record completion separately; they do not change independent mastery evidence.

Source `b04e354` sends chosen answer indexes and a stable per-attempt UUID. The authenticated server validates a complete answer set against the lesson, grades it, and records its checksum. The database stores one immutable completion per student and submission ID. Identical retries return successfully; altered payloads using the same identity fail. The endpoint requires an unlocked diagnostic and is executable only by the server role. Account changes remount the lesson player, and offline guided practice no longer updates skill estimates either. The completion message no longer claims an estimate update.
